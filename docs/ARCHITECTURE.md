# Architecture

## Node reference
| # | Node | Role |
|---|---|---|
| 1 | Vapi Discovery Webhook | POST endpoint for Vapi `end-of-call-report` |
| 2 | Normalize Vapi Payload | Code node; extracts structured output, transcript, contact and discovery fields into one flat item |
| 3 | Google Docs - Create Client Inquiry | Creates the inquiry doc |
| 4 | Google Drive - Move Inquiry to Folder | Files it in the inquiries folder |
| 5 | Google Docs - Write Client Inquiry | Writes call details and transcript |
| 6 | Google Docs - Get Client Inquiry | Reads the doc back as the source of truth for the AI |
| 7 | Analyze Discovery Call and Draft Proposal | AI Agent (OpenAI chat model + Brave Web Search tool); writes 13-section proposal with strict evidence rules |
| 8 | Validate AI Proposal Output | IF node; passes only if all 13 required `##` headings exist |
| 9 | Prepare Proposal Package | Builds title, status flags and doc links |
| 10 | Google Slides - Create Proposal | Creates the blank presentation |
| 11 | Build Slides Batch Requests | Code node; converts the proposal into Slides API `batchUpdate` requests (14 slides, custom layouts per section) |
| 12 | Google Slides - Populate Proposal | HTTP Request to the Slides API |
| 13 | Google Drive - Move Proposal to Folder | Files the deck in the proposals folder |
| 14 | Prepare Google Slides Log Metadata | Builds the log row |
| 15 | Upsert Discovery Call Log | Writes the run to the data table |
| - | Log AI Analysis Failure | Error branch; logs `AI_ANALYSIS_FAILED` |

## Required proposal sections (13)
Executive Summary, Discovery Findings, Current-State Workflow, Pain Points and Business Impact, Automation Opportunities, Recommended Solution, Future-State Workflow, Recommended Tools and Alternatives, Architecture and Integrations, Data, Security and Access, Implementation Roadmap and Acceptance Criteria, Risks, Assumptions and Validation, Investment, Success Metrics and Next Steps. Plus a cover slide = 14 slides.

## Evidence rules enforced in the prompt
No invented metrics, prices, ROI, dates or guarantees; the caller's confirmed statements are the only client facts; recommended tools are labelled as the agency's recommendation, not client preference; unknowns are marked "Not provided - confirm during technical discovery".

## Status values
`PROPOSAL_DRAFT_CREATED_IN_GOOGLE_SLIDES` on success, `AI_ANALYSIS_FAILED` when the agent fails or validation does not pass.

## Known limitations
- Slides are generated by code, so layout changes require editing the Build Slides Batch Requests node.
- Columns named `canva_*` are legacy names; they now hold Google Slides status and URL.
- The Slides batch step fails if the proposal has fewer or differently named sections than expected; the validator guards this.
